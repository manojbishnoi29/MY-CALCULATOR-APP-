# My Media Folder

Upload your photo or video files directly into this folder.

### Supported File Formats:
- **Videos (will automatically play on loop in the app's corner):**
  - `.mp4`
  - `.webm`
  - `.mkv`
  - `.mov`

- **Photos & GIFs (will display in the app's corner):**
  - `.jpg` / `.jpeg`
  - `.png`
  - `.gif`
  - `.webp`

### How to Change Media Without Updating the App:
1. Delete the current file in this folder on GitHub.
2. Upload and commit your new photo or video file here.
3. Whenever the calculator app has internet access, it will automatically detect and play your new media in the corner!
